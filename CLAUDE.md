# tecnologias 
esta app estara desplegada con docker, backend en node.js con express, frontend en react, base de datos mysql

# concepto de la app.
esta app sera para llevar los gastos ingresos, cada gasto o ingreso tiene que llevar una categoria o no, y un lugar a donde va o sale (eso si es obligatorio), las categorias dependen si son ingreso o egreso 

# partes

tiene que tener una dasboar donde se vea el valance, otra parde donde ingrese los datos de movimiento (solo para eso), una parte donde de las metricas como cuanto gasto en el mes en que y asi, una parde de setting donde se configura la cuenta y las categorias
